# GLP-1 Companion v5.0.2

Final migration candidate after the five v5 architecture phases.

- Vite-oriented source structure
- Tailwind CSS v4 local/compiled
- JavaScript split into ordered domain modules
- Firebase Modular bridge (Auth, Firestore, App Check, AI Logic)
- Rebuilt PWA/service-worker update lifecycle
- Schema remains 13 for data compatibility
- Minimum compatible cloud client remains v4.1.2

The GitHub deployment package is produced separately from this source tree.
